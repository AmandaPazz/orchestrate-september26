# Buy or Wait? — Solution

Deterministic 90-day cash-flow forecast decides every output field; an LLM (Anthropic or
Gemini) is used only for three narrow extraction tasks (image amount extraction, message
amendment interpretation, decision-explanation writing) and never influences a numeric or
categorical decision directly.

## Setup

1. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

2. Provide an API key. Only one is required — Anthropic is tried first if configured, else
   Gemini. Copy `.env.example` (in the repo root, one level up from this file) to `.env`
   and fill in whichever key you have:

   ```bash
   cp ../.env.example ../.env
   # then edit ../.env:
   #   ANTHROPIC_API_KEY=...
   # or
   #   GEMINI_API_KEY=...
   ```

   `.env` is loaded automatically on every run (via `python-dotenv`) — no manual
   `export`/`$env:` needed. A real environment variable, if already set, always takes
   precedence over `.env`.

   If neither key is available, the pipeline still runs to completion: every LLM call has
   a graceful, deterministic fallback (unresolved amounts are excluded per the spec's own
   rule rather than guessed; message-driven salary facts fall back to structural
   recurrence detection; `decision_explanation` falls back to a grounded template).

## Running

From the repository root:

```bash
python3 code/main.py
```

This reads every CSV under `dataset/`, produces one row per `dataset/requests.csv` entry,
and writes:

| Output | Location |
|---|---|
| Predictions | `output.csv` (repository root) |
| Token usage / cost report | `code/evaluation/usage_report.md` |
| Pipeline diagnostic log | `code/run_log.txt` (exclusions, downgrades, safety-check overrides, call failures — distinct from the AGENTS.md chat-transcript `log.txt` at the repo root) |
| LLM response cache | `code/cache/llm_cache.json` (keyed by call type + input hash; re-running costs $0 for any previously-seen input) |
| Circuit-breaker state | `code/cache/llm_exhausted.json` (which model/provider pairs hit a quota wall today, so a fresh run doesn't re-attempt a known-dead one) |

A full run against the real `dataset/requests.csv` (250 rows) takes several minutes when
LLM calls are actually made, dominated by Gemini's free-tier rate limit (15 requests/minute
on the model this was built against) rather than by the deterministic computation itself,
which completes in seconds.

## Tests

```bash
python3 -m unittest discover -s tests
```

33 tests, all synthetic (constructed fixtures, no real data or API calls needed) covering
code paths the real 250-request dataset never exercises on its own: ranking tie-break
levels 4-6 (real data never produces more than 2 simultaneously eligible candidates for a
single request), the 2- and 3-change spending-change search paths (real data only ever
needs 1), and the message-derived-amount magnitude sanity check (including the
household-consolidation exception and its adversarial-abuse guard).

## Design notes

- **No LLM call ever sets a decision field directly.** Every JSON schema an LLM call can
  return is a narrow, whitelisted shape (an amount, a confidence level, a fact type) with
  no field corresponding to `affordability_status`, `recommended_payment_method`, or any
  other output column — verified with an adversarial test simulating a fully compromised
  model attempting to smuggle those field names directly into its JSON response.
- **A deterministic magnitude sanity check** (`forecast.py`) does not trust a model's
  self-reported confidence alone for a large salary-amount change: a claimed jump of more
  than 50% from the series' real recent history is downgraded to low confidence regardless
  of what the model reported, unless it carries an explicit future-dated `effective_date`
  that plausibly explains it (a raise, a new contract).
- **Provider fallback**: Anthropic first if `ANTHROPIC_API_KEY` is set, else Gemini via a
  chain of models (quotas are tracked per-model on Gemini's free tier, confirmed from a
  real `429` error's own `quotaId`), with an in-memory-and-disk-persisted circuit breaker
  so a model already known exhausted today is never re-attempted.
